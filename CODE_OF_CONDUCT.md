# Code of Conduct

## Our Pledge

We want participation in **Windows Icon Refresher** to be welcoming, constructive, and respectful.

Contributors, maintainers, and users are expected to communicate professionally and treat others with respect regardless of experience level, background, identity, or perspective.

## Expected Behavior

Examples of positive behavior include:

- Giving constructive feedback
- Respecting different technical opinions
- Helping users without belittling them
- Staying focused on the project
- Accepting reasonable maintainer decisions
- Correcting mistakes openly
- Assuming good intent where reasonable

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment or intimidation
- Personal attacks
- Threats
- Discriminatory or demeaning language
- Deliberate disruption
- Publishing another person's private information without permission
- Repeated hostile or inflammatory behavior
- Sexualized language or imagery in project spaces

## Project Spaces

This Code of Conduct applies to project spaces including:

- GitHub Issues
- Pull requests
- Discussions
- Code review comments
- Other official project communication channels

## Enforcement

Project maintainers may edit, hide, remove, or reject comments, contributions, Issues, or pull requests that violate this Code of Conduct.

Serious or repeated violations may result in temporary or permanent removal from project spaces.

## Reporting

If you experience or witness unacceptable behavior, report it privately to the repository owner through an appropriate contact method listed on their GitHub profile.

Please do not use a public Issue to report sensitive conduct concerns.

Reports will be reviewed as fairly and confidentially as practical.
